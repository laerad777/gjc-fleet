# Fleet dashboard font notices

Fleet Display and Fleet Text are locally embedded, renamed Latin subsets from the Fraunces and Inter fonts in the dashboard design. No font is fetched at runtime. The fonts remain under SIL OFL 1.1, separate from the Fleet project license. Subsetting and WOFF conversion do not change glyph design.

Fraunces embedded source copyright: Copyright 2020 The Fraunces Project Authors (github.com/undercasetype/Fraunces).

- Fraunces 400: original mock font SHA-256 `3eb6cf0a14feb1876cc464fa093af4e0c5b05dc46dec65619c1d95f2a1ab5aa7`. Local WOFF subset: 20620 bytes.
- Fraunces 600: original mock font SHA-256 `ff7cf63717c27756df857ca12045a83522569f7b561bedaff813a25274eb263f`. Local WOFF subset: 20664 bytes.
- Inter 300: original mock font SHA-256 `d0f4bc7faca468376e3db9b5e57afcdc2192134c9ac82a9511f32767b56853a4`. Local WOFF subset: 22104 bytes.
- Inter 400: original mock font SHA-256 `1b08e7fc267a5c7e1d614100f604b83e7e8a0be241f0f288faa2b3ac93a683ba`. Local WOFF subset: 21944 bytes.
- Inter 600: original mock font SHA-256 `e7a1aaf7eda9f2fad4131725fa556265ec75ca7b2d756260173a040363e8d4f7`. Local WOFF subset: 22440 bytes.
